# 워크데스크 v2-1

사용자 요청에 따라 v2와 독립적으로 만든 관리자 대시보드. Hallmark 2.0.0 Coral 테마(deal 3/3)의 웜 그레이, 잉크색, 코랄 상태 색상을 사용한다. Pretendard는 기존 v2의 로컬 폰트를 재사용한다. 테마의 장식, 외부 폰트, 질감 SVG는 적용하지 않는다.

## 구조와 재사용
HTML, CSS, JS를 분리한다. theme.css에 색과 간격 토큰, common.css에 공통 컴포넌트, main.css에 화면 배치를 둔다. 실제 정의한 text + small/medium/large/xlarge 및 type2 조합을 사용한다. 최대 콘텐츠 너비 1480px, 분기점 1280px와 768px. 상단 탐색, 미처리 요약, 접수일별 현황, 긴급 요청, 요청 목록, 팀별 미처리 현황으로 구성한다. 이후 화면은 이 시스템을 따른다.

## 실행 및 데이터
index.html을 직접 열면 동작한다. 외부 네트워크, 빌드, 패키지가 필요하지 않다. js/dummydata.js 하나가 샘플 요청과 담당자의 원본이다. 모든 수치와 차트는 목록에서 계산한다. 차트의 완료 수는 해당 접수일 요청 중 현재 완료된 수이며 처리일별 완료량이 아니다. 기준일은 2026-11-17이다.

검색, 상태 필터, 페이지는 URL hash로 보존한다. 검색, 페이지 이동, 요청 생성, 제목/담당자/우선순위/상태/메모 수정, 필터 결과 CSV 다운로드를 제공한다. 수정은 메모리에만 반영되며 새로고침 시 초기화된다. 서버 저장이나 실제 인증은 제공하지 않는다. 동기 로컬 데이터이므로 가짜 로딩을 두지 않는다. 빈 검색 결과, 폼 오류, 데이터 파일 누락 오류를 제공한다. 신규 아이콘은 제작하지 않았고 calendar.svg만 기존 v2에서 복사했다.

## 모바일
표의 데스크톱 열을 중복 표시하지 않고 같은 요청 셀에 담당자, 상태, 우선순위, 접수일을 모두 표시한다. 요청 상세 편집은 모달 대신 문서 하단 인라인 폼이다.

## 검증 결과
file:// Chrome에서 320, 390, 768, 769, 1280, 1440, 1920px 화면, 폰트·아이콘 로딩, 가로 넘침 없음 확인. 검색/빈 결과/필터/새로고침 후 필터 유지/페이지 이동/상태 수정/새 요청 등록/CSV 다운로드 검증. JavaScript 런타임 오류 없음. qa/check.cjs 및 qa/desktop.png, qa/mobile.png 참고. Hallmark 정적 검사 0 FAIL / 0 REFLEX / 0 WARN. 내장 렌더는 puppeteer-core 미설치로 미실행했으며 Playwright로 별도 검증했다.

375px 전체 화면 추가 검증. 독립 시각 검토에서 발견한 모바일 안내 문구 줄바꿈을 짧은 문장과 단어 단위 줄바꿈으로 수정했다. 차단 시각 결함 없음.

## 배경 움직임
사용자의 최종 요청에 따라 선 효과를 작은 코랄 계열 꽃잎이 천천히 내려오는 Canvas 배경으로 교체했다. 데스크톱 14개, 모바일 8개를 양쪽 여백에 분산한다. 낙하 속도 초당 20~32px, 작은 좌우 흔들림과 회전으로 움직인다. 화면 중심과 텍스트·표·차트 뒤는 불투명 표면을 유지한다. 색은 theme.css의 기존 코랄과 파생 토큰을 사용한다. 외부 이미지나 라이브러리는 필요하지 않다.

상단 정지/재개 버튼과 저장된 사용자 선택을 유지한다. 모션 감소 설정, 사용자 정지, 비활성 탭에서는 requestAnimationFrame을 취소한다. Canvas는 접근성 트리와 포인터에서 제외하고 DPR은 2로 제한한다. 구현은 js/background.js에 분리한다. 스크롤로 선을 그리는 효과는 사용하지 않는다.
