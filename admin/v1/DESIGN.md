# 이음 시스템 v2

## 기준
사용자 제공 관리자 화면 이미지를 기준으로 Hallmark 2.0.0의 app screen / custom 흐름을 적용했다. 이미지의 파란 레일, 연한 회색 메뉴, 조직 트리, 검색 폼, 녹취 결과 표를 따른다. 화면 구성은 Hallmark 기준을 유지하며, 사용자 추가 요청에 따라 입력·셀렉트와 날짜·시간 피커는 kws-ui-v2 원본을 재사용한다. 아이콘 및 컴포넌트 출처는 assets/sources.json에 기록한다. 이음 로고는 새로 제작한 벡터이며 인라인 SVG를 사용하지 않는다.

## 레이아웃
- **브라우저 너비 100%, 최대 너비 제한 없음.** 1920px 고정 화면이 아니다. 사용자의 명시 요청으로 Hallmark의 컨테이너 상한 규칙 대신 이 계약을 적용한다.
- 데스크톱: 60px 레일 / 180px 업무 메뉴 / 나머지 콘텐츠. 조직 트리 204px, 결과는 남은 공간 전체를 사용한다.
- 분기점은 1280px, 768px만 사용. 모바일은 메뉴 토글, 조직 목록 내부 스크롤, 결과 표 가로 스크롤을 사용한다.
- HTML/CSS/JS 분리. 공통 스타일 css/common.css, 토큰 css/theme.css, 화면 스타일 css/main.css. 실행 동작이 없는 theme.js는 만들지 않는다.

- 레일 버튼 폭 44px, 좌우 여백 각 8px. 어두운 선택 배경 대신 밝은 파란 선택 배경을 사용한다. 메뉴 접힘 시 회색 배경 16px을 남긴다. 메뉴 트랙·내부 콘텐츠를 240ms로 전환하고, 모션 감소 환경에서는 전환하지 않는다. 접힌 메뉴는 inert로 키보드 탐색에서 제외한다.

## 디자인 토큰과 컴포넌트
Pretendard 로컬 가변 폰트. text + small/medium/large/xlarge, type1/type2. 공통 button / primary, input, control, dialog를 사용한다. 색상은 theme.css의 의미 기반 토큰으로만 관리한다. 파란색은 탐색·선택·포커스, 초록색은 검색 작업과 관심·정상 상태에 사용한다. 상태에는 텍스트를 동반한다. 신규 화면도 동일한 토큰과 구성 요소를 재사용한다.

## 동작과 데이터
js/dummydata.js 하나에 126개 합성 녹취 및 조직 데이터를 둔다. 기준일은 2026-11-17이다. 각 화면 인스턴스는 원본을 복사해 독립 상태를 가진다. 조직, 검색 조건, 페이지는 URL hash에 기록한다. 메모, 관심 등록, 선택, 다운로드 이력은 메모리 상태이므로 새로고침하면 초기화된다.

검색·범위 검증·정렬·페이지 이동·행 선택·상세·메모·관심 등록·CSV 다운로드를 지원한다. CSV는 실제 음성이 아닌 목록이다. 실제 인증, 고객정보, 음성 재생, 서버 저장, 실시간 모니터링은 연결하지 않았다. API 로딩이 없는 동기 로컬 데이터이므로 인위적인 로딩 화면은 두지 않았다. 데이터 없음과 입력 오류 상태를 제공한다.

## 검증
file://로 Chrome에서 390, 768, 769, 1280, 1920, 2560px 너비 확인. 검색 결과·행 선택·CSV 다운로드·상세·메모 적용·페이지 이동·역전 날짜 오류를 검증했다. JavaScript 런타임 오류 없음. 초기 Hallmark 화면의 정적 검사 결과는 0 FAIL / 0 REFLEX / 0 WARN이었다. 이후 요청으로 KWS 원본 입력·피커 스타일을 도입했으며 해당 원본 치수와 팔레트를 우선한다. Hallmark 내장 렌더는 puppeteer-core 미설치로 실행되지 않았으며 별도 Playwright로 직접 파일 렌더와 동작을 확인했다. 데스크톱·모바일 스크린샷은 qa/에 있다.

추가 검증: file://에서 1440/1280/900px 레일 좌우 여백 8px 실측, 메뉴 전환 중간 폭과 양방향 완료 상태, 접힌 메뉴 inert, 16px 잔여 배경, 모바일 메뉴와 피커 화면 경계, reduced-motion, 날짜 선택, 시간 방향키·Escape 포커스 복귀, 피커 재초기화 후 중복 없음, 종료 입력만 범위 오류 표시, 셀렉트 검색 반영을 확인했다. KWS 원본의 밝은 입력 테두리와 회색 텍스트 팔레트는 유지했다.

## 선택 요소 통일
체크박스·라디오는 KWS 원본 control-input / control-icon 및 상태별 SVG를 사용한다. 표의 전체 선택과 동적으로 생성되는 행도 동일 계약을 사용하며 native checked/disabled/indeterminate 및 기존 이벤트를 유지한다. 검색 버튼은 KWS button.type2의 색상·테두리·상태를 적용하고 기존 검색 영역의 높이와 가로 안쪽 여백은 유지한다. 검색 항목·상담 유형·녹취 상태·페이지 크기 셀렉트 네 곳 모두 input.select를 사용한다. 드롭다운 옵션 목록은 KWS 원본과 동일하게 native select다.

검증: 네 셀렉트의 클래스와 화살표, 정적·동적 체크박스와 라디오, 선택/비활성 SVG, 라디오 기간 변경, 키보드 포커스, 검색 및 기존 사이드바 여백·접힘 전환 회귀를 file://에서 확인했다.

전체 선택은 현재 페이지의 미선택/일부 선택/전체 선택을 동기화한다. 일부 선택은 checked=false, indeterminate=true이며 네이티브 indeterminate 상태를 유지하면서 선택된 KWS 체크박스에서 파생한 가로선 SVG를 표시한다. 사용자 요청으로 흰색 2px 선, 4px 모서리, 20px 크기, 동일한 파란 배경을 사용한다. 일부 선택에서 클릭 또는 Space로 현재 페이지 전체가 선택된다. file://에서 세 상태의 표시·전환, 개별 해제, 페이지 이동 후 상태 복원, 키보드 조작을 검증했다.
