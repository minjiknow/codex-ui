# 국립중앙도서관 메인

기준 화면은 2026년 11월 20일 국립중앙도서관 메인이다. HTML 파일을 직접 열어 실행한다. 도서·소식·휴관일은 확인일의 정적 콘텐츠다. 홈과 문서 내부 이동만 연결한다. 별도 목적지가 없는 항목은 링크 주소를 비워 두고, 검색 제출 시 미리보기 안내를 표시한다. 설문 팝업은 원본 설문 기간에만 표시한다.

## 메인과 공통 스타일

본문의 최대 너비는 1280px이다. 더미 배너는 데스크톱·모바일 이미지를 구분한다. Pretendard와 색상 토큰은 css/theme.css에서 관리한다. 공통 헤더와 메뉴는 css/common.css 및 js/common.js, 메인 전용 구성은 css/main.css 및 js/main.js에서 관리한다. 배너·도서 표지·소식 썸네일·퀵메뉴·설문 이미지는 국립중앙도서관 화면 구성을 참고해 제작한 미리보기용 PNG다. 보도·행사 장면은 AI로 생성한 예시 이미지다. 도서·WEB DB 표지 23종, 소식·누리소통망 썸네일 10종, 퀵메뉴 이미지 8종은 항목별로 연결한다. 재사용한 로고·조작 아이콘·폰트의 원본 URL은 assets/sources.tsv에 기록했다.

## 메뉴

여섯 개 대분류와 하위 링크는 도서관 메뉴를 기준으로 한다. 국립중앙과학관을 참고한 210px 제목 영역, 분류 목록과 상세 링크 영역을 사용한다. 팝업 배경은 --surface-muted로 통일하며 닫기 버튼은 24px close.svg를 사용한다. 서브메뉴의 3px 밑줄은 #8a7b5c이며, 포인터 진입과 키보드 포커스 시 0.3초 동안 왼쪽에서 오른쪽으로 펼쳐지고 이탈 시 0.25초 동안 줄어든다. 동작 줄이기 설정에서는 즉시 전환한다.

대분류 버튼을 다시 누르거나 바깥을 누르면 패널이 닫힌다. Escape는 열린 하위 분류부터 닫고 해당 버튼에 초점을 돌려준다.

## 푸터와 정적 데이터

푸터에는 연락처, 이용 안내, 누리소통망, 정책, 저작권과 관련단체 목록을 표시한다. 관련단체 전체 화면은 닫기 버튼 또는 Escape로 닫으면 여는 버튼으로 초점이 돌아온다. 메인의 예시 데이터는 js/dummydata.js에서 관리하고 index.html의 template을 복제해 표시한다.
